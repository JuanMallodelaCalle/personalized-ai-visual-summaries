# Personalized AI Visual Summaries
**Personalized AI-generated visual summaries for text conversations**

## Description
This repository contains code, datasets, prompts and results for the generation of personalized, AI-created images summarizing text-based dialogues.

## Structure
- `data/` – Datasets, dialogues and persona profiles
- `prompts/` – Prompt engineering scripts and templates
- `scripts/` – Code for automation, API calls, evaluation, etc.
- `images/` – Selected result images
- `results/` – JSON outputs, generated visual plan

## How to use
1. **Setup:**
   Clone the repo and install requirements:
   ```bash
   git clone https://github.com/JuanMallodelaCalle/personalized-ai-visual-summaries.git
   cd personalized-ai-visual-summaries
   pip install -r requirements.txt
2. **Extending Persona Profiles:**
   Run scripts in scripts/extend_profiles.py or refer to Jupyter notebooks.
3. **Generating Prompts:**
   Use notebooks or scripts in prompts/.
4. **Image Generation:**
   Use OpenAI API (see scripts/openai_image_gen.py)
5. **Evaluation:**
   (WIP) Evaluation scripts and human voting web app in evaluation/.
